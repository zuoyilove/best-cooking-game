Sizzle & Serve · 深夜食堂 — a complete original cooking game that runs in a desktop browser from static files with no network request. Take orders from the board, pick ingredients off the counter, stack the dish on the assembly plate and serve it before the timer runs out. Orders arrive faster as the shift wears on, combos pay extra, and three strikes end the night.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — mouse or keyboard (1-6 ingredients, Space serve, Backspace trash)
```
